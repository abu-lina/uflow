# Flow: hotfix

```
Fix -> Done
```

| Phase    | Subagent      | Skills                   | What it does                                                                           |
| -------- | ------------- | ------------------------ | -------------------------------------------------------------------------------------- |
| **Fix**  | `implementer` | `diagnosing-bugs`, `tdd` | Reproduces, writes the regression test first, applies the minimal fix, runs the suite. |
| **Done** | Orchestrator  |                          | Presents the summary. Push and deploy are the user's call.                             |
