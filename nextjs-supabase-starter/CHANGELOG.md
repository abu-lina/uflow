# Changelog

All notable changes to this project will be documented in this file.

The format is based on [Keep a Changelog](https://keepachangelog.com/en/1.0.0/),
and this project adheres to [Semantic Versioning](https://semver.org/spec/v2.0.0.html).

## [1.0.0] - 2024-12-01

### Added

- Initial release of Next.js + Supabase Starter Template
- Next.js 15 with App Router
- Supabase authentication (email/password)
- TypeScript support
- Tailwind CSS with custom design system
- Authentication pages (login, signup, forgot password, reset password)
- Protected dashboard page
- Middleware for route protection
- Server-side rendering support
- TanStack Query for data fetching
- Toast notifications with Sonner
- Comprehensive documentation (README, ARCHITECTURE, SETUP guides)
- Database migration for user profiles
- Row Level Security policies
- ESLint and Prettier configuration
- Loading spinners and UI components

### Security

- Implemented Row Level Security (RLS) for database
- PKCE flow for authentication
- Secure cookie handling for server-side auth
- Environment variable validation
