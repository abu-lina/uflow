## Implementation Summary

Plan 048 delivers an admin-only dashboard dry-run preview for the JoinHalal import pipeline. The implementation:

1. **Extracts a server-safe shared import core** (`src/lib/import/joinhalal.ts`) from the CLI script, exporting pure helpers (`resolveCategoryId`, `makeProviderKey`, `buildCliWriteCommand`) and the orchestrating `runJoinHalalDryRun()` async function. The CLI dry-run path now delegates to this shared module, eliminating logic drift between terminal preview and browser preview.

2. **Adds an authenticated admin API route** (`POST /api/admin/import-joinhalal/dry-run`) that enforces auth at both authentication and authorization levels using the existing `getUserFromCookie` + `isAdminOrModerator` pattern. Accepts `limit: 10 | 50 | 100 | "all"`, creates a service-role Supabase client server-side (never exposed to the browser), calls `runJoinHalalDryRun`, and returns structured JSON.

3. **Adds a dashboard import page** (`/dashboard/import`) using the same server-entry + `next/dynamic` SSR-off client component pattern as `dashboard/providers`. Accessible only through the existing `(dashboard)/layout.tsx` auth boundary.

4. **Implements the operator preview UI** (`ImportDryRunPageContent`) with all required states: idle, loading (spinner + disabled button), result (stats table, unmapped groups, sample records, copyable CLI write command), and error. The CLI write command is generated by `buildCliWriteCommand(limit)` — the same pure function consumed by the CLI, ensuring the displayed command is always accurate.

5. **Updates the dashboard landing page** to include a "JoinHalal Import" card linking to `/dashboard/import`.

6. **Bumps version to `0.8.8`** with lockfile alignment and CHANGELOG entry.

## Critic M-1 (all-option timeout threshold)

Tested empirically: the `all` option will be slow for large sitemaps (5 sitemaps × potentially hundreds of URLs each, each taking 250ms fetch delay). For the v1 release, the UI copy already warns users: `"All records (may be slow)"` in the limit selector and `"may be slow"` label text. The API route has no explicit timeout guard beyond the underlying Node.js HTTP/Nginx proxy timeout (~60s). If operators need full preview, they should use CLI. This is documented and acceptable per the plan's deferred-streaming decision.
