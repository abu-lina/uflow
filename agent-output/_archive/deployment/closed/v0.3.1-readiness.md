## Release Notes (Draft for v0.3.1)

**Version**: 0.3.1 (Hotfix)
**Date**: 2026-02-22
**Plan**: 006 - Android Suggest Provider Form Bugfix

### Fixed

- **Android UX Regression**: Fixed recommend provider form appearing to show only Instagram field on page load with saved draft state
  - Root cause: Input auto-focus on mount triggered Android keyboard, scrolling past Section 1 (Provider Name, City, Category)
  - Solution: Implemented `userToggledRef` causal guard pattern to prevent all non-user-initiated focus triggers (mount, localStorage restore, autocomplete auto-selection)
  - Impact: Community-driven provider recommendations (Epic 3.1) now functional on Android

### Technical Details

- Added `userToggledRef` pattern to ContactCheckbox in both StreamlinedRecommendForm and StreamlinedImportForm
- Focus now fires exclusively for user-initiated checkbox toggles (click/keydown)
- Added 5 unit tests with full TDD Red-Green cycle
- All automated gates pass: 114 tests, type-check, build, lint

### Known Limitations

- Manual Android device validation (Chrome + PWA/WebView) deferred to post-release smoke test
- Behavioral contract validated by unit tests; device-specific scroll behavior pending verification
