### Commit Message

```
fix(pwa): Fix iPhone map tile rendering regression from Plan 208

Service Worker runtimeCaching regex matched all OSM tile PNG URLs,
causing CacheFirst handler to intercept tile requests. On iOS Safari,
concurrent cache evictions during rapid zoom/pan caused silent handler
failures — tiles returned no response, rendering grey.

Three surgical fixes:
- Scope SW image cache regex to Supabase storage URLs only (no longer
  intercepts tile.openstreetmap.de requests)
- Remove crossOrigin: 'anonymous' from Leaflet tile layer (unnecessary
  for this codebase; forced CORS mode amplified iOS WebKit failures)
- Correct CSP connect-src from tile.openstreetmap.org to .de (matches
  actual configured host; defense-in-depth)

Adds regression test suite (pre-fix FAILS / post-fix PASSES) guarding
all three fix components.

Refs #313
Co-Authored-By: Claude <noreply@anthropic.com>
```
