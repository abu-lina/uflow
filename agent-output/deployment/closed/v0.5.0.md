## Release Summary

### Version: v0.5.0
**Type**: Minor  
**Environment**: Production  
**Epic**: Cross-cutting quality refactor

### Changes Overview

**Security (P0)**:
- Removed 4 localhost ingest calls from splash components (`SplashContent.tsx`, `MobileSplashScreen.tsx`) that would fail on user devices
- Added safety regression test (`no-localhost-ingest.test.ts`) to prevent future production-risk debug calls

**Performance (P1a)**:
- `/providers` page now server-renders initial search results (faster time-to-content)
- New route handler `GET /api/providers/search` as pagination boundary with explicit caching headers
- 60s cache TTL for browse (no query), `no-store` for free-text queries
- Reduced client bundle coupling (pagination via API route instead of direct service import)

**Architecture (P1b)**:
- Removed explicit `force-dynamic` exports from root layout and root page
- Routes remain dynamic via inherent API usage (`headers()`, `cookies()`)
- Documented inherent dynamism with clear comments

**Testing**:
- 8 new unit tests (route handler + safety regression)
- 147 tests passing, 0 failures
- All quality gates passed: type-check, delta-lint, build
