## Release Summary

This release packages the post-merge Iconify hotfix that removes the explicit Workbox `NetworkOnly` route for Iconify CDN JSON endpoints. The route caused service-worker-context fetches, which Firefox ETP and some content blockers can block at network level. Browsers now fetch the Iconify JSON directly without service-worker interception.
