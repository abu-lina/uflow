# Plan 255 C6 — Human translation review needed (ar / tr / ur / ps)

Plan 255 introduced new user-visible strings in `de.ts` and `en.ts`. The four
remaining locales (`ar`, `tr`, `ur`, `ps`) were **seeded with the German source
text as an interim**, marked `// INTERIM de (#415)` or wrapped in a
`// Plan 255 INTERIM` comment block at the end of each file.

**None of the strings below are translated.** A native speaker must review and
replace every one of them in `src/translations/{ar,tr,ur,ps}.ts`. The interim
text exists so `npm run i18n:check` passes and users see German rather than a
raw key string.

## Where to apply

Each locale file (`src/translations/ar.ts`, `tr.ts`, `ur.ts`, `ps.ts`) contains:

- `// INTERIM de (#415)` inline markers next to `suchen.was.*`,
  `navigation.saved`, and `providerDetail.proofTier.pendingReview`
- one `// Plan 255 INTERIM` block at the end of the file holding `halal.*`,
  `submissionValidation`, `submissionStatus`, `createPage`, `createHalal`,
  `adminHalalEdit`

Replace the German values in place. When done, `npm run i18n:check` must still
pass (it only checks key presence, not content).
