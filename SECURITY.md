## Reporting a Vulnerability

We take security vulnerabilities seriously. If you discover a security vulnerability, please follow these steps:

### 1. **Do NOT** disclose publicly
- Do not open a public GitHub issue
- Do not discuss the vulnerability in public forums
- Do not create a public pull request

### 2. Report privately
Please email security concerns to: **security@ummahflow.com**

Include the following information:
- Description of the vulnerability
- Steps to reproduce
- Potential impact
- Suggested fix (if any)

### 3. What to expect
- **Acknowledgment**: We'll acknowledge receipt within 48 hours
- **Initial Assessment**: We'll provide an initial assessment within 7 days
- **Updates**: We'll keep you informed of our progress
- **Resolution**: We'll work to resolve the issue as quickly as possible

### 4. Responsible Disclosure
We follow responsible disclosure practices:
- We'll credit you (if desired) for reporting the vulnerability
- We'll work with you to understand and resolve the issue
- We'll coordinate public disclosure after a fix is available

## Security Best Practices

### For Users
- Keep your account credentials secure
- Use strong, unique passwords
- Enable two-factor authentication when available
- Report suspicious activity immediately

### For Developers
- Follow secure coding practices
- Keep dependencies up to date
- Review security advisories regularly
- Test security patches before deployment

## Security Features

- ✅ Rate limiting on authentication endpoints

- ✅ HTTPS/TLS encryption
- ✅ Content Security Policy (CSP)
- ✅ Secure session management
- ✅ Regular security audits
