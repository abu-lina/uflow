# Curated skill catalog for this project.
#
# Every SKILL.md discovered under a skills root has its name and description
# injected into the system prompt of EVERY session. With 838 skills installed
# that was ~69k tokens of fixed overhead before the first user message.
#
# This file is the allowlist. Skills listed here stay active; everything else
# is archived (moved, not deleted) to ~/.cursor/skills-archive.
#
# Selection criteria, in order:
#   1. Matches the actual stack in package.json (Next.js App Router, React,
#      TypeScript, Tailwind, MUI, Supabase/Postgres, TanStack Query, next-intl,
#      Vitest, Playwright, Testing Library, Zod).
#   2. Matches the agent workflow in .devin/skills/orchestrator/SKILL.md
#      (worktrees, subagent dispatch, phase gating, plan/spec docs).
#   3. Cross-cutting engineering judgment that applies to most changes.
#
# Excluded on purpose: every other-language/other-cloud cluster (Azure SDK,
# .NET, Java, Rust, Go, Python web, mobile/native, Unity/Unreal), offensive
# security and pentest tooling, and the SaaS-connector long tail. Restore any of
# them with: scripts/context/archive-skills.sh --restore <name>
#
# Lines starting with # are comments. One skill directory name per line.
