**Learning:** Supabase PostgREST can't ORDER BY a foreign table column without a foreign key relationship, so the city-population sort has to run in-app after the DB fetch — the DB query uses `provider_name + provider_id` for deterministic pagination, and the in-app sort re-orders each page by city population.
