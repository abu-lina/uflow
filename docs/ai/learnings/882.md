---
title: Role-aware UI conditions on shared detail pages
issue: 882
---

**Learning:** When a detail page is viewed by both submitters and admins, conditional UI (banners, warnings) must branch on `isAdmin` for copy and on `review_status` for visibility gates. A null/unanswered field is not the same as a denied field; gate admin-only warnings on `review_status === 'approved'` so pending providers with unanswered attestations don't trigger false alerts.
