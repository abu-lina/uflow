**Learning:** The halal tier filter is pushed into the SQL WHERE clause using PostgREST's `!inner` join on `food_providers`. This excludes providers without a `food_providers` row entirely. Bronze/silver use compound `.or()` conditions with `{ foreignTable: 'food_providers' }` to match multiple attestation combinations. Gold uses simple `.eq()` + `.not()` filters. `computeSealTier()` is used only for display rendering (ProofTierCard), not for search filtering.
