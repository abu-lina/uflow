# useLayoutEffect prevents hydration flash for locale detection

**Learning:** `useLayoutEffect` runs synchronously before the browser paints, so switching from `useEffect` to `useLayoutEffect` for locale detection eliminates the intermediate re-render that causes duplicate DOM elements (the flaky Playwright strict-locator failure). In jsdom, discriminate the two hooks by wrapping them via `vi.mock('react')` and tracking which phase is active when a side-effect fires.
