# Review subagents get the diff from a bundle file, not from exec

**Learning:** A Devin subagent profile can only grant whole tools, so a reviewer can't have "exec for `gh pr diff` only"; a read-only `scripts/review-bundle` run by the foreman plus a `read`/`grep`/`glob` profile is the only way to give reviewers the diff without a write path.
